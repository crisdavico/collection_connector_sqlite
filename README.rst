Read-only SQLite seller, customer, and invoice source for Collections.

**Development and test data only.** This connector is a sample data
source for local development and automated tests. Never install it in a
production database: every install and module upgrade recreates the
sample ``database.sqlite`` from ``data/database.sql``, points the
**SQLite Sellers** connector at it again (overwriting any path set on
that connector), and assigns it to the main company when that company
has no connector. The seedian parent repository links this addon only
when ``DOODBA_ENVIRONMENT=devel``.

Adds connector type ``sqlite`` with an absolute ``sqlite_path``. Only
system administrators (``base.group_system``) can read or change
``sqlite_path`` and download the file. After rejecting relative paths,
``?`` ``#`` NUL, and any file whose first 16 bytes are not the SQLite
header (``SQLite format 3\0``), the addon opens ``file:<path>?mode=ro``
against
``sellers(id TEXT PRIMARY KEY, name TEXT NOT NULL, mobile TEXT, active INTEGER NOT NULL DEFAULT 1, commission_percent REAL NOT NULL DEFAULT 0 CHECK 0–100)``,
``customers(id TEXT PRIMARY KEY, seller_id TEXT NOT NULL, name TEXT NOT NULL, identification TEXT NOT NULL UNIQUE, customer_code TEXT NOT NULL UNIQUE, active INTEGER NOT NULL DEFAULT 1)``,
and
``invoices(id TEXT PRIMARY KEY, customer_id TEXT NOT NULL, number TEXT NOT NULL UNIQUE, issue_date TEXT NOT NULL, due_date TEXT NOT NULL, amount REAL NOT NULL, balance REAL NOT NULL, state TEXT NOT NULL, document_kind TEXT NOT NULL DEFAULT invoice CHECK invoice|quotation)``.
Missing, unreadable, non-SQLite, or invalid schema raises ``UserError``
without path or SQL, and a non-SQLite file is never offered for
download. Success does not write the file. Depends on ``collection``.
Admins can run Test Connection on the connector form. Customer listing
and customer debt are seller-scoped and stay in this addon;
``collection`` does not import or open SQLite.

Install and upgrade materialize ``data/database.sql`` as
``database.sqlite`` under Odoo ``data_dir``, create the **SQLite
Sellers** connector, assign it on the main company when none is set, and
expose the file for download to administrators on the connector form.
Customer debt reads outstanding ``open``/``overdue`` invoices and
quotations (``document_kind``) with positive balance. Test Connection
remains sellers-only.
